# TINGGSFOOD — Website Resep Masakan

Website resep statis dengan HTML, CSS, dan JavaScript murni.

## Menjalankan secara lokal
1. Ekstrak ZIP.
2. Buka folder `TINGGSFOOD`.
3. Buka `index.html` di browser, atau gunakan Live Server di VS Code.

## Struktur file
- `index.html` — struktur halaman dan formulir tulis resep.
- `style.css` — desain responsif.
- `recipes.js` — 10 data resep yang disesuaikan dengan foto di folder `assets/`.
- `script.js` — pencarian, filter kategori, detail, favorit, dan tambah resep lokal.
- `assets/` — 10 foto makanan dari ZIP yang diberikan.

## Catatan
Foto bawaan disimpan lokal di folder `assets`, jadi tidak perlu mengambil foto resep dari internet. Google Fonts masih memerlukan internet; bila offline, website menggunakan font cadangan. Favorit dan resep yang ditambahkan hanya tersimpan di browser/perangkat ini karena website belum memakai backend.
